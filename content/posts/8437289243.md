> Windows 11 + NVIDIA GTX 1660 Ti（6GB GDDR6）

---

## 你的显卡到底能干什么？

以 GTX 1660 Ti（6GB GDDR6 / 1536 CUDA 核心 / 288 GB/s 带宽）为例。它没有 **Tensor Core**，所以不能跑带 TensorRT 加速的大模型推理。

> 即使没有Tensor Core，也不影响跑Ollama

显存是硬约束：

| 模型级别     | 显存占用   | 体验                               |
| ------------ | ---------- | ---------------------------------- |
| 1B~3B        | 1~3 GB     | 🟢 秒加载，极流畅（>80 tok/s）      |
| 4B~5B        | 2.5~4 GB   | 🟢 非常流畅（60~90 tok/s）          |
| 7B~8B（Q4）  | 4.5~6 GB   | 🟡 可运行，需关 Chrome 等占显存应用 |
| 7B~8B（Q5+） | 5.5~6.5 GB | 🔴 可能 OOM，不推荐                 |
| 14B+         | 8 GB+      | ❌ 显存不足                         |

---

## 环境准备：30 秒自查

```
nvidia-smi
```

驱动要求其实很宽松：**≥ 452.39 即可**（GTX 1660 Ti 出厂驱动远高于此，通常不用更新）。系统内存建议 16GB（7B 模型需要系统内存做后备）。CUDA Toolkit 一般不用装——**Ollama 自带 CUDA 运行时**，只有做开发/训练才需要手动装。

---

## 安装：两步 + 一个强烈建议

下载 [Ollama](https://ollama.com) 的 Windows 安装包，双击即可，它会自动注册为后台服务。

**强烈建议先改模型存储路径**：模型文件动辄几 GB，默认在 C 盘，建议挪到F盘：

1. 在目标盘建目录，如 `F:\ollama\models`；
2. 打开系统环境变量，新建用户变量 `OLLAMA_MODELS` = `F:\ollama\models`；
3. 重启 Ollama 生效。

验证：`ollama --version`。

## 模型选择：按场景挑

**入门首选（速度最快、体验最佳）**

| 模型          | 拉取命令                  | 大小    | 速度      | 特点                   |
| ------------- | ------------------------- | ------- | --------- | ---------------------- |
| **Phi-4**     | `ollama pull phi4:3.8b`   | ~2.3 GB | ~95 tok/s | 微软出品，推理能力越级 |
| **Qwen3-4B**  | `ollama pull qwen3:4b`    | ~2.6 GB | ~70 tok/s | 中文最佳，支持工具调用 |
| **Llama 3.2** | `ollama pull llama3.2:3b` | ~2.0 GB | ~80 tok/s | Meta 出品，生态最丰富  |

**进阶（能力更强，显存紧张）**：Qwen2.5-7B（128K 上下文，中文王者）、Llama 3.1 8B、Mistral 7B。

**场景专用**：DeepSeek-R1:7B / 1.5B（思维链推理、数学逻辑）、Qwen2.5-Coder:7B（代码生成，HumanEval ~75%）。

**一键下载的学习入门套装（不到 10 GB）**：

```
ollama pull phi4:3.8b           # 日常对话 + 快速实验
ollama pull qwen3:4b            # 中文场景 + Agent 学习
ollama pull deepseek-r1:7b      # 推理思维链
ollama pull nomic-embed-text    # Embedding 模型（RAG 学习用）
```

## 运行：三个高频参数即可

```
ollama run qwen3:4b                          # 交互对话（/bye 退出）
ollama run phi4:3.8b "用一句话解释 Transformer"
ollama run deepseek-r1:7b --temperature 0.3  # 降低随机性，输出更确定
ollama run qwen2.5:7b -c 2048 --temperature 0.7 --top-p 0.9
```

| 参数               | 说明                                | 建议值       |
| ------------------ | ----------------------------------- | ------------ |
| `-c` / `--context` | 上下文窗口（token），**最影响显存** | 2048 或 4096 |
| `--temperature`    | 输出随机性                          | 0.1~1.5      |
| `--top-p`          | 核采样概率                          | 0.9          |

监控显卡：另开终端 `nvidia-smi -l 1`。

## 集成：HTTP API + Web UI

Ollama 启动后自动在 [http://localhost:11434](http://localhost:11434) 提供 REST API。

```
import requests
def ask_ollama(prompt: str, model: str = "qwen3:4b"):
    r = requests.post("[http://localhost:11434/api/generate](http://localhost:11434/api/generate)",
        json={"model": model, "prompt": prompt, "stream": False,
              "options": {"temperature": 0.7, "num_ctx": 2048}})
    return r.json()["response"]
print(ask_ollama("用 Python 写一个冒泡排序"))
```

想要界面，直接上 **Open WebUI**（类 ChatGPT，支持 RAG、多模型切换），Docker 一键启动：

```
docker run -d -p 3000:8080 \
  -e OLLAMA_BASE_URL=[http://host.docker.internal:11434](http://host.docker.internal:11434) \
  --name open-webui \
  ghcr.io/open-webui/open-webui:main
```

然后浏览器开 `[http://localhost:3000](http://localhost:3000)`。

## 性能优化：显存紧张时记住这"三板斧"

1. **限制上下文长度**（最重要）：默认 2048 就行，7B 模型别硬开 4096；
2. **跑 7B 前关掉 Chrome / VS Code**——它们会偷 1~2GB 显存；
3. **不要同时加载多个模型**。

关于量化，一张表看懂：

| 量化   | 质量     | 体积（7B） | 6GB 显卡              |
| ------ | -------- | ---------- | --------------------- |
| Q4_K_M | 几乎无损 | ~4.5 GB    | ✅ 推荐（Ollama 默认） |
| Q5_K_M | 更好     | ~5.5 GB    | ⚠️ 勉强                |
| Q8_0   | 接近原始 | ~7 GB      | ❌ 会 OOM              |

另外，把模型放 NVMe SSD（通过 `OLLAMA_MODELS` 指定）能明显加快加载。

## 常见问题排查表

| 现象                 | 原因          | 解决                             |
| -------------------- | ------------- | -------------------------------- |
| `CUDA out of memory` | 显存不足      | 换小模型，或 `-c 2048`           |
| GPU 未被检测         | 驱动问题      | `nvidia-smi` 检查，确保 ≥ 452.39 |
| `connection refused` | Ollama 未启动 | 从开始菜单启动                   |
| 模型下载慢           | 网络问题      | 重试，或设代理环境变量           |
| 回答突然变慢         | KV Cache 满了 | `/clear` 或重启对话              |
| 下载的模型找不到     | 路径问题      | 检查 `OLLAMA_MODELS`             |
